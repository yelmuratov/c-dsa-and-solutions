1. Grade statistics
Read up to 100 grades into an array. Functions: read_grades, find_max, find_min, calculate_average, print_grades. Teaches: declaring arrays, indexing, passing arrays to functions, integer vs double division. ✅

2. Array toolkit
Functions: reverse(arr, n), contains(arr, n, value), count_occurrences(arr, n, value), sum(arr, n). Fill an array from user input, then run each function and print results. Teaches: modifying arrays in place, linear search, returning found/not-found. ✅

3. Sorting
Implement bubble_sort(arr, n) and is_sorted(arr, n). Bonus: selection_sort as a second version. Print the array before and after. Teaches: nested loops, swapping elements, comparing algorithms. ✅

4. Word tools (strings)
Strings are char arrays. Read a word with fgets, then write string_length (no strlen), is_palindrome, to_uppercase, count_vowels. Teaches: char arrays, the '\0' terminator, why you shouldn't use scanf("%s").

5. Todo list (challenge)
Fixed-size array of strings (char tasks[20][100]) with a count variable. Menu: add task, remove task by index, list tasks, exit. Removing must shift later elements left. Teaches: 2D char arrays, keeping size separate from capacity, shifting — exactly the ideas a dynamic list will need.
