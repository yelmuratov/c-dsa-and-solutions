1. Temperature converter
Write functions like celsius_to_fahrenheit(float c) and fahrenheit_to_celsius(float f). Ask the user for a number, call the right function, print the result. Teaches: float, scanf, printf, return values.

2. Simple calculator
Four functions: add, subtract, multiply, divide. Read two numbers and an operator, print the answer. Bonus: make divide handle division by zero.

3. BMI / shape calculator
Functions like circle_area(float r), rectangle_area(float w, float h), triangle_area(...). Good practice for passing multiple arguments.

4. Tip & bill splitter
Input: bill amount, tip percent, number of people. Functions: calculate_tip, calculate_total, split_bill. Feels like a real app.

5. Unit converter (challenge)
Kilometers ↔ miles, kilograms ↔ pounds, etc. Write one function per conversion, plus a small "menu" function that prints the options.
